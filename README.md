# Elina — ресторан для хомячков

Казуальная браузерная игра. Повар «Розовый нос» готовит и разносит еду гостям ресторана Elina.

## Как играть
Откройте `index.html` в браузере (или `python -m http.server` в этой папке → http://localhost:8000).

- Клик по блюду на нижней панели (или по плите / клавиши 1–6) — повар идёт готовить.
- Клик по гостю или его столику — повар берёт готовое с раздачи и относит.
- Клик по блюду на раздаче — выбросить лишнее. Клик по повару — отменить приказы.
- Кроссовок / Пробел — ускорение. Колпак — «Кухня» (улучшения за монеты). Esc — пауза, M — звук.

С каждым днём больше столиков (3 → 6), разнообразнее меню (бургер → пицца, кофе, суп, салат, кекс) и плотнее наплывы гостей.

Игра занимает весь экран: на квадратном/широком экране — как на референсе (по бокам зал продолжается),
на высоком телефоне HUD прижат к верху, кухня и панель блюд — к низу, а столы встают в две колонки с проходом.
Повар и гости ходят по проходам (A* по сетке зала), никогда не наступая на столы и стулья.

## Проверка ботами
```
node tools/bot-sim.js 10 12          # 3 бота (pro / casual / slow) × 10 дней × 12 сидов + проверка инвариантов
EXT=1250 node tools/bot-sim.js 10 8  # то же для высокого телефона (EXT — добавленная высота зала)
```
Боты ловят: зависания повара, переполнения, «путь не найден» и любое прохождение сквозь столы.
В браузере бот играет сам: `index.html?level=7&bot=pro&speed=2` (bot = pro | casual | slow).

## Инспектор (сравнение с референсом)
```
node tools/screenshot.js        # снимки в shots/ через headless Chrome/Edge
```
`index.html?demo=1` — кадр, расставленный как на референсе `reference/reference.png`; его сравнивает агент-инспектор.

## Структура
- `js/logic.js` — игровая логика (без графики, работает и в Node)
- `js/bot.js` — боты-игроки
- `js/art.js` — вся графика, процедурно на canvas
- `js/main.js` — экраны, ввод, эффекты, сохранение (localStorage)
